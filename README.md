# 小三花桌面宠物

一个使用 Python 3.11/3.12、uv 和 PySide6 编写的 Windows 桌面宠物。窗口透明、无边框并保持置顶；小猫可以拖动，左键抚摸，右键打开中文菜单。

## 启动

先安装 [uv](https://docs.astral.sh/uv/)，然后在项目目录运行：

```powershell
uv run --python 3.12 calico-pet
```

首次启动时，uv 会准备 Python 3.12 并安装项目依赖。也可以使用 `uv run --python 3.12 python -m calico_pet` 启动。

## 交互

- 左键单击小猫：抚摸并提升心情、亲密度，同时挥爪回应。
- 按住左键拖动：移动小猫在桌面上的位置。
- 右键：喂食、玩耍、睡觉/叫醒、查看状态、修改名字或退出。
- 饱食度、心情、精力和亲密度均限制在 0–100；状态会随时间变化并在退出/定时保存。
- 重启会读取上次状态并补算离线期间的变化。

## 文件与状态

- `assets/calico_spritesheet.png`：透明三花猫精灵图；全部非空格都被切帧使用，包含待机、左右走动、挥爪、蹦跳、眨眼、歪头、独立踩奶、闭眼睡觉及多方向张望。
- `assets/calico_pose_sheet.png`：neutral 姿态加全身与近景两组 16 方向转头帧；浅灰底会在切帧时移除。neutral 与主图的体型不同，已从 idle 循环移除。
- `assets/calico_sleep_sheet.png`：透明趴睡图，按检查过的明确裁剪边界提取；原帧姿态差异较大，正式播放改用源帧 1 生成的轻微呼吸循环，原始 8 帧保留供检查。资源不可用时回退到 Qt 绘制的闭眼蜷卧姿势。
- idle、walk、睡觉和各类动作均由 `QTimer` 逐帧驱动；醒着时跟随光标，抚摸时挥爪，玩耍时蹦跳再走动。互动与存档逻辑保留。
- 如果图片不存在或无法读取，程序会改用 Qt 绘制的三花猫占位图。
- 宠物状态和窗口位置保存在当前 Windows 用户的应用数据目录 `CalicoPet/pet_state.json`，不会写入项目目录。

## 开发验证

```powershell
uv run --python 3.12 python -m compileall src
uv run --python 3.12 python -m unittest discover -s tests
```

此应用是桌面 GUI 程序，启动后可从小猫右键菜单退出。

## 动画对齐与独立预览

```powershell
.\.venv\Scripts\python.exe -m calico_pet.preview
# 仅导出编号图和逐帧坐标，不打开窗口
.\.venv\Scripts\python.exe -m calico_pet.preview --export-only
```

预览工具不读写宠物存档。支持动作选择、上一帧/下一帧、进度条、暂停、1 FPS 慢放、正常播放、原始裁剪（含异常帧）及固定锚点参考线。支持连续首尾循环检查。

处理后的单帧和原始/对齐编号图位于 `artifacts/animation/`；`frames.json` 记录图集尺寸、透明通道、源裁剪矩形、非透明边界、身体锚点、统一缩放比例、平移坐标、起伏及排除原因。原 PNG 素材保持不变。

所有动画画布为 192×208，身体参考锚点为 (96, 201)。坐姿以身体下部与脚底定位；趴睡以胸腹接触区域定位；走路按固定躯干采样带定位，避免收腿改变身体高度，叠加 ±1 像素轻微起伏。每组使用同一缩放比例，初始化时缓存 QPixmap，绘制时不裁边、不缩放。宠物窗口固定为 192×242，拖拽仍可移动位置。

已检查的图集：主图 1536×2288（有 alpha，192×208 网格）；姿态图 1536×1170（无 alpha，按 234 像素行距跳过标签）；睡觉图 1774×887（有 alpha）。睡觉裁剪列边界明确记录为 x=0/450/894/1342/1774，行边界 y=0/450/887，不依赖整除推断。透明识别阈值为 alpha>8，睡觉额外保留最大连通主体以清除散落噪点。当前所有主体都未触及裁剪边缘；没有发现切到邻近角色的证据。

播放间隔：待机 140 ms（7.14 FPS，包含停留）、走路 110 ms（9.09 FPS）、互动 130 ms（7.69 FPS）。睡觉使用同一稳定姿态生成 32 帧呼吸，100 ms/帧（10 FPS），每轮 3.2 秒；水平位置和宽度不变，以地面为支点做最大 1.8% 的轻微纵向呼吸，首尾采用余弦曲线平滑衔接。所有呼吸帧在初始化时缓存，不在刷新时变换。移除了额外绘制的橙色摇尾曲线、睡眠气泡及 z 字。近景转头原图本来就只有胸部以上，未伪造缺失身体。

`sleep_raw.png` 和 `sleep_aligned.png` 仍用于检查原始姿态；正式呼吸帧导出为 `sleep_breathing_01.png` 至 `sleep_breathing_32.png`，编号图为 `sleep_breathing_aligned.png`。预览工具选择 sleep 的正常模式与桌宠一致，勾选 Raw 时可查看原始姿态跳变。

Windows 验证：先在预览工具中对照参考线，检查两轮左右行走、坐姿、趴睡及首尾衔接；切换 Raw 可看到睡觉第 7 帧仍保留在原素材中。再运行桌宠，验证拖拽、抚摸、喂食、玩耍、睡觉/叫醒、改名和退出后重启的存档。自动测试采用 Windows Qt offscreen，不能代替真人桌面观感验证。
